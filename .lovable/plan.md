# GarmentOS — визуальное направление Precision Atelier (утверждено)

Прототип frontend. Без backend, БД, Supabase, auth и API. Только данные из ТЗ; чего нет — empty state.

## Направление: Precision Atelier

Индустриальная точность производственной системы + сдержанная премиальность fashion-бренда. Плотный, тихий, инженерный интерфейс: бумажная база, графитовый текст, один сигнальный акцент. Без декоративности, без крупных скруглений, без градиентов.

## Дизайн-система

**Тема:** светлая профессиональная (многочасовая работа с таблицами).

**Палитра**
- Фон приложения: `oklch(0.985 0.002 90)` — тёплый бумажный
- Поверхность: белый, отделяется границей, а не тенью
- Текст: графит `oklch(0.22 0.01 260)`; вторичный `oklch(0.52 0.012 260)`
- Границы: `oklch(0.91 0.004 90)`, 1px — основной инструмент разделения
- Акцент: индиго-стальной `oklch(0.52 0.14 258)` — действия, активная навигация, фокус
- Сигнальные: success `oklch(0.55 0.11 155)`, warning `oklch(0.68 0.13 75)`, danger `oklch(0.55 0.19 27)`

**Типографика**
- Заголовки/UI: Inter Tight, tracking-tight, вес 600
- Текст: Inter
- Числа, суммы, ID, даты: JetBrains Mono, tabular-nums, выравнивание вправо
- Шкала: 11 / 12 / 13 / 14 / 16 / 20 / 28 / 36. База UI и таблиц — 13px, подписи — 11px uppercase

**Spacing:** сетка 4px. Строка таблицы 40/48px (переключатель плотности). Карточка 16–20px, страница 24px, контент до 1440px.

**Радиусы:** 6px база, 8px карточки/дровер, 4px бейджи и инпуты, 999px только точки статусов и аватары.

**Тени:** границы + `0 1px 2px rgb(0 0 0 / 0.04)` для карточек; настоящая тень только у поповеров, дропдаунов, дровера.

**Иконки:** inline SVG-набор проекта (stroke 1.5px, 16px в UI, 14px в таблицах), монохром, цвет наследуется. Новая библиотека иконок не устанавливается.

**Статусы:** 6px точка + label, 11px uppercase, тонкая граница, фон 8% цвета. Набор статусов партии = ровно этапы ТЗ.

## Навигация

Левый рельс 240px (сворачивается в 56px), разделы строго по ТЗ:
Главная, Партии, Модели, Цеха, Материалы, Закупки, Склады, Поставщики, Документы, Финансы.
Верхняя полоса 52px: хлебные крошки, поиск, контекстные действия. Никаких дополнительных разделов и вкладок.

## Экран 2 — Паспорт партии #158

Порядок: что это → сколько денег → где партия → что требует внимания → детали.

1. **Шапка:** `#158` моноширинно, модель, цех, статус-бейдж, действия.
2. **Деньги:** суммы по партии из данных ТЗ, моноширинно, в одну линию. Ничего расчётного сверх имеющегося.
3. **Где партия:** горизонтальный степпер ровно из пяти этапов —
   Черновик → Размещён → В производстве → Готово к отгрузке → Принято.
   Без процента готовности, без плановых/фактических дат этапов, без подэтапов (крой/пошив/ВТО/упаковка/логистика/отгрузка не существуют).
4. **Требует внимания:** ровно одна позиция —
   Неоплаченный счёт — 864 000 ₽, срок до 28.08.2026.
   Больше ничего не показывать.
5. **Детали:** только разделы, для которых есть данные в ТЗ. Пустые — как empty state, не как выдуманное содержимое.

## Технические детали

- Токены в `src/styles.css` (Tailwind v4 `@theme inline` + `:root`), цвета в oklch; токены `--surface`, `--border-strong`, `--accent`, `--status-*`, `--shadow-card`, `--shadow-overlay`
- Шрифты через `<link>` в `src/routes/__root.tsx` (Inter, Inter Tight, JetBrains Mono), семейства в `@theme`
- shadcn (new-york) с переопределёнными вариантами: Button, Badge (статусы), Table (плотный), Tabs (подчёркивание)
- Мок-данные строго из ТЗ в `src/data/`
- Иконки — локальный inline-SVG модуль, без новых зависимостей
