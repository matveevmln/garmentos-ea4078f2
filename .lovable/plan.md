# GarmentOS — визуальное направление и дизайн-система

Одно утверждённое направление. Без вариантов, без backend, без полного билда.

## Направление: "Precision Atelier"

Индустриальная точность производственной системы + сдержанная премиальность fashion-бренда. Плотный, тихий, инженерный интерфейс: нейтральная бумажная база, графитовый текст, один сигнальный акцент. Никакой декоративности, никаких больших скруглений, никаких градиентных карточек.

## Ключевые решения

**Тема:** светлая по умолчанию (многочасовая работа с таблицами и документами), тёмная — как второй режим на тех же токенах.

**Палитра (light)**
- Фон приложения: `oklch(0.985 0.002 90)` — тёплый бумажный, не белый
- Поверхность карточек: чистый белый, отделяется границей, а не тенью
- Текст: графит `oklch(0.22 0.01 260)`; вторичный `oklch(0.52 0.012 260)`
- Границы: `oklch(0.91 0.004 90)` — тонкие, 1px, основной инструмент разделения
- Акцент: индиго-стальной `oklch(0.52 0.14 258)` — только для действий, активной навигации и фокуса
- Сигнальные: success `oklch(0.55 0.11 155)`, warning `oklch(0.68 0.13 75)`, danger `oklch(0.55 0.19 27)`, info-neutral серый
- Финансовые дельты: зелёный/красный только в цифрах, не в фонах

**Типографика**
- Заголовки/UI: Inter Tight (плотный, техничный)
- Текст: Inter
- Числа, суммы, артикулы, даты: JetBrains Mono с tabular-nums — денежные и количественные колонки всегда моноширинные и выровнены по правому краю
- Шкала: 11 / 12 / 13 / 14 / 16 / 20 / 28 / 36. Базовый UI — 13px, таблицы — 13px, подписи — 11px uppercase tracking-wide
- Заголовки: tracking-tight, вес 600; никаких 800/900

**Плотность и spacing**
- Сетка 4px. Строка таблицы 40px (compact) / 48px (default) — переключатель плотности
- Отступ карточки 16–20px, отступ страницы 24px, максимум контента 1440px
- Секции разделяются линиями и заголовками-эйрбарами, а не большими пустотами

**Радиусы:** 6px базовый, 8px карточки/модалки, 4px бейджи и инпуты, 999px только для аватаров и точек-статусов. Ничего сверх 8px.

**Тени:** почти отсутствуют. Границы + едва заметная `0 1px 2px rgb(0 0 0 / 0.04)` для карточек; настоящая тень (`0 12px 32px / 0.12`) только у поповеров, дропдаунов и дровера.

**Иконки:** Lucide, stroke 1.5px, размер 16px в UI и 14px в таблицах; монохром, цвет наследуется от текста. Никаких заливок и цветных иконок кроме статусных точек.

**Статусы:** текстовый бейдж = 6px точка + label, 11px uppercase, тонкая граница, фон 8% цвета. Пять состояний: план / в работе / задержка / на проверке / закрыто. Прогресс — тонкая 4px линия, не кольцо.

**Навигация:** постоянный левый рельс 240px (сворачивается в 56px иконочный), сгруппированный по доменам: Обзор, Партии, Цеха, Материалы, Закупки, Документы, Финансы. Верхняя полоса высотой 52px: хлебные крошки, глобальный поиск (⌘K), контекстные действия справа. Никаких вкладок верхнего уровня.

## Экран 1 — Главная (Обзор дня)

Порядок сверху вниз:
1. Полоса KPI: 4–5 плотных метрик в одну строку (в производстве, к отгрузке на неделе, просрочено, к оплате, маржа месяца). Крупные моноширинные числа, микро-дельта, без иконок в кругах.
2. «Требует внимания» — приоритетный список рисков (просрочки, нехватка материалов, неоплаченные счета) с прямым действием в строке.
3. Производственный поток — партии по стадиям в виде компактной таблицы-канбана (колонки-стадии, строки-партии), а не крупных карточек.
4. Правая колонка 320px: движение денег за неделю и ближайшие обязательства.

## Экран 2 — Паспорт партии #158 (главный экран)

Строгий порядок ответов: что это → сколько денег → где партия → что требует внимания → детали.

1. **Шапка-идентичность (sticky):** `#158` моноширинно, название модели, цех, статус-бейдж, дедлайн с обратным отсчётом, действия справа.
2. **Денежная полоса:** себестоимость / оплачено / остаток к оплате / плановая маржа — 4 моноширинных числа в одной линии с разделителями, без карточек.
3. **Где партия:** горизонтальный степпер стадий (крой → пошив → ВТО → упаковка → отгрузка) с фактом/планом по датам и процентом готовности; под ним — количества по размерам/цветам.
4. **Внимание:** блок отклонений — брак, нехватка материала, сдвиг срока, просроченный платёж. Красная/жёлтая левая линия, не заливка.
5. **Детали:** табы одного уровня — Материалы, Операции и оплата труда, Документы, Финансы, История. Внутри — плотные таблицы с моношириной в числах, инлайн-редактирование, боковой дровер вместо модалок.

## Технические детали

- Токены в `src/styles.css` (Tailwind v4 `@theme inline` + `:root`/`.dark`), все цвета oklch; новые токены: `--surface`, `--surface-muted`, `--border-strong`, `--accent`, `--status-*`, `--shadow-card`, `--shadow-overlay`, `--density-row`
- Шрифты через `<link>` в `src/routes/__root.tsx` (Inter, Inter Tight, JetBrains Mono), семейства — в `@theme` (`--font-sans`, `--font-display`, `--font-mono`)
- Библиотека UI — shadcn (new-york) с переопределёнными вариантами: Button (без крупных радиусов), Badge (статусные варианты), Table (плотный вариант), Tabs (подчёркивание, не пилюли)
- Никакого backend: экраны на локальных мок-данных в `src/data/`
