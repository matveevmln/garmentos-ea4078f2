# GarmentOS

Перед началом разработки хочу уточнить технический момент. Для этой задачи мне нужен только frontend-прототип: одна responsive-кодовая база, интерактивный UI, без backend, БД, Supabase, авторизации и API. После завершения мне понадобится использовать созданный frontend как визуальный и технический референс для переноса дизайна в существующий GarmentOS через Claude Code.

Подтверди, пожалуйста:

Сможешь ли ты создать такой прототип за один проход?

В каком виде я смогу получить исходный frontend-код проекта после создания?

Сохранятся ли React/CSS/компоненты и responsive-логика, чтобы другой разработчик мог использовать их как основу?

Можно ли будет получить/экспортировать весь исходный код без необходимости отдельно генерировать HTML для каждого экрана?

Нужно ли мне вообще просить тебя генерировать скриншоты, или достаточно готового preview и исходного кода?

Какие действия в таком проекте расходуют кредиты, и как лучше организовать задачу, чтобы не тратить кредиты на ненужные итерации?
